# 運用リスク修正の確認

確認日: 2026-10-03（日本時間）

対象: RoleShuffle v4.5.3 build503 / `version/4.5.3`

## 修正範囲

[build502の全役職監査](role-safety-build502.md)のA1・A5・A6を修正しました。

- **A1 / Tuna:** 前フレームとの差ではなく、最後に移動と認めた位置からの変位で判定します。小さな移動も積み重なるため、高フレームレートや低速移動で静止扱いになる問題を防ぎます。
- **A5 / Tuna:** 蘇生ごとに、生存して操作できる状態へ戻ってから5秒間の猶予を設けます。死亡通知・蘇生通知・役職変更・プレイヤー再接続でも静止状態をリセットします。トラック内は静止ダメージを停止し、外へ出た後に静止時間を数え直します。通常の静止ダメージは引き続き死亡につながります。
- **A6 / Trickster:** 設置待ちの物体を本人に紐付けて管理し、役職喪失・離脱時に直ちに破棄します。設置完了前にも、同じ設置要求・同じプレイヤー・能力の有無・生存・トラック外・期限を確認します。古い設置処理が再開しても、新しい設置を消さないようにしています。

## 保留した項目

ユーザーの指定により、**Mage・BodyguardのHP処理（A2・A3）と、Mage・Tricksterの表情操作（A4）は変更していません**。

通信遅延時のMageの支払い超過、Bodyguardの肩代わりによる死亡、参加者のメニュー終了時の表情による誤発動は未解消です。残量を直接指定するHP方式と、参加者のチャット発動への限定は採用していません。
