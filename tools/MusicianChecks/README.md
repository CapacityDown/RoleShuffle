# Musician regression checks

Run `dotnet run --project tools/MusicianChecks -c Release` from the repository root.

Links production healing and instrument hooks; covers shared cooldowns, combined
stage budgets, local partial heals, remote reservations, identity continuity,
continuous audio gates and context eligibility. Inspects installed R.E.P.O. v0.5.0
hook targets and fields. Deterministic stand-ins do not replace live multiplayer
or audio verification.
